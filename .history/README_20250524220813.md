# 🛒 Connectify - Electronics E-commerce Platform

## 📋 **OVERVIEW**
Connectify là một nền tảng thương mại điện tử chuyên về thiết bị điện tử, được xây dựng với Spring MVC và MySQL. Hệ thống cung cấp đầy đủ tính năng quản lý sản phẩm, đơn hàng, người dùng và hỗ trợ cả giao diện admin và user.

## ✨ **FEATURES**

### **🔐 Authentication & Authorization**
- JWT-based authentication
- Role-based access control (Admin/User)
- Secure password handling
- Session management

### **📦 Product Management**
- CRUD operations for electronics
- Category and brand management
- Image upload and serving
- Advanced search and filtering
- Stock management

### **🛒 Shopping Cart & Orders**
- Add/remove items from cart
- Order placement and tracking
- Invoice generation
- Order status management

### **👥 User Management**
- User registration and profile management
- Admin user management
- Role assignment
- Password reset functionality

### **📊 Admin Dashboard**
- Comprehensive statistics
- Revenue reports
- User analytics
- Product insights
- Order management

## 🔧 **TECH STACK**
- **Backend**: Spring MVC 5.3.21
- **Database**: MySQL 8.0
- **Build Tool**: Maven 3.6+
- **Server**: Apache Tomcat 7
- **Java**: JDK 11
- **Authentication**: JWT
- **ORM**: Hibernate/JPA

## 🌐 **API ENDPOINTS**

### **🔓 Public APIs**
```http
GET  /electronics              # List all products
GET  /electronics/{id}         # Get product details
GET  /electronics/search       # Search products
GET  /categories               # List categories
GET  /brands                   # List brands
GET  /images/{imageName}       # Serve images
POST /auth/login               # User login
POST /auth/signup              # User registration
```

### **👤 User APIs (Requires Authentication)**
```http
GET    /users/me               # Get current user info
GET    /carts/get              # Get user's cart
POST   /carts/add              # Add item to cart
DELETE /carts/delete-items     # Remove items from cart
GET    /invoices/user          # Get user's orders
POST   /invoices               # Create new order
```

### **🔒 Admin APIs (Admin Only)**
```http
# User Management
GET    /admin/users/statistics
POST   /admin/users
PUT    /admin/users/{userId}
DELETE /admin/users/{userId}

# Product Management
POST   /electronics
PUT    /electronics/update
DELETE /electronics/{id}
GET    /admin/products/statistics

# Order Management
GET    /admin/orders
GET    /admin/orders/{invoiceId}
PUT    /admin/orders/bulk-status
```

## 🔐 **AUTHENTICATION**

### **Login**
```bash
curl -X POST http://localhost:1512/auth/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "email=admin@connectify.com&password=admin123"
```

### **Using JWT Token**
```bash
curl -X GET http://localhost:1512/admin/users/statistics \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## 📊 **DATABASE SCHEMA**

### **Main Tables**
- **users**: User accounts and profiles
- **electronics**: Product catalog
- **categories**: Product categories
- **brands**: Product brands
- **carts**: Shopping cart items
- **invoices**: Order records
