# 🛒 Connectify - Electronics E-commerce Platform

## 📋 **OVERVIEW**
Connectify là một nền tảng thương mại điện tử chuyên về thiết bị điện tử, được xây dựng với Spring MVC và MySQL. Hệ thống cung cấp đầy đủ tính năng quản lý sản phẩm, đơn hàng, người dùng và hỗ trợ cả giao diện admin và user.

## ✨ **FEATURES**

### **🔐 Authentication & Authorization**
- JWT-based authentication
- Role-based access control (Admin/User)
- Secure password handling
- Session management

### **📦 Product Management**
- CRUD operations for electronics
- Category and brand management
- Image upload and serving
- Advanced search and filtering
- Stock management

### **🛒 Shopping Cart & Orders**
- Add/remove items from cart
- Order placement and tracking
- Invoice generation
- Order status management

### **👥 User Management**
- User registration and profile management
- Admin user management
- Role assignment
- Password reset functionality

### **📊 Admin Dashboard**
- Comprehensive statistics
- Revenue reports
- User analytics
- Product insights
- Order management

## 🔧 **TECH STACK**
- **Backend**: Spring MVC 5.3.21
- **Database**: MySQL 8.0
- **Build Tool**: Maven 3.6+
- **Server**: Apache Tomcat 7
- **Java**: JDK 11
- **Authentication**: JWT
- **ORM**: Hibernate/JPA
